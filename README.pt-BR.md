\# Controle Financeiro Pessoal – Aplicação Desktop em Python



Aplicação desktop desenvolvida em Python para controle financeiro pessoal, com foco na prática de desenvolvimento de software, integração com banco de dados e organização de informações.



\## 🚀 Funcionalidades

\- Sistema de autenticação de usuários

\- Dashboard financeiro com saldo, entradas, saídas e metas mensais

\- Classificação de gastos e controle de recorrência

\- Geração de relatórios em PDF, Excel e gráficos

\- Persistência de dados utilizando MySQL



\## 🛠 Tecnologias

\- Python

\- MySQL

\- Tkinter

\- Git e GitHub



\## 📊 Objetivo do Projeto

Projeto criado com o objetivo de aplicar conceitos de programação, banco de dados e desenvolvimento de software em um contexto prático e próximo de situações reais.



\## ▶️ Como executar

1\. Clone o repositório

2\. Instale as dependências necessárias

3\. Configure o banco de dados MySQL

4\. Execute o arquivo principal em Python



\## 📌 Observações

Este é um projeto pessoal com foco em aprendizado e evolução técnica.
